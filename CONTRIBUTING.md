# Contributing

Use Node.js 22.19+ or 24.11+ on Linux or macOS. Run `npm ci`, `npm test` and `npm run build`, then check your changes in the browser with `npm run dev`. In your pull request, explain what changed and how you checked it.

Keep CV editing, imports and exports local, with no tracking or required paid services. Keep secrets and private account captures out of the repository. Write original code, copy and assets, and record public research sources and known limits in `docs/research/`. Follow the existing code style. Keep older save files working, or include a tested migration.
